# Dependencies and shared contracts
Status: proposed v1; owners must review before replacing existing APIs.
Canonical IDs: lowercase ASCII snake_case, immutable, unique per namespace; chapter IDs 1..26, act IDs 1..10, dungeon IDs abyss/stair with floors 1..100. Narrative display text localized separately (it/en); never use display text as identity. JSON records carry schema version, stable ID, explicit references; reject missing references and cycles where invalid. Units: Unreal centimeters, seconds, degrees; Blender meters with explicit conversion. Gameplay events carry source entity ID, target entity ID, event type, chapter/quest context and unique event ID for deduplication. Save owns authoritative persisted state; quest consumes validated events; UI reads presentation snapshots; art references registry IDs, not arbitrary filenames.
01 establishes framework boundaries; 02/03/04 consume combat/RPG interfaces; 05 consumes presentation snapshots; 06/08 coordinate state transitions and idempotent quest rewards. 07/09 own canon and disclosure timing; 08 maps narrative to quest graph. 10–15 author art/audio independently against registry conventions; 16/17 consume environment kits and stable POI IDs; 18 validates exported geometry/materials/licenses; 19 owns build gates; 20 independently validates all. All departments may work on isolated files immediately. Runtime integration awaits contract review; final assets await render/import checks; release awaits actual engine and platform authorization.
