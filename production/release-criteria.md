# Acceptance and release gates
M0: repository manifests, schema validation and ownership recorded. M1: UE5.6 Win64 compile, package executable plus dependencies, launch and combat smoke test with keyboard/controller, logs tied to commit. M2: play First Descent end-to-end, Noah reveal, save/load and defeat recovery; no blocking defects. M3: all 26 chapters, 200 distinct floor designs and four endings reachable in engine; automated graph checks plus actual playthrough evidence; no narrative deadlocks or reward duplication. M4: final asset provenance, mesh/UV/material/rig validation, render review, animation/audio integration, no unapproved placeholders. M5: full campaign playtests, accessibility and Italian/English localization checks, performance profiling against agreed hardware (budgets set after M2), zero critical/blocking defects; reproducible signed-off Win64 artifact. M6: authorized platform-specific build and certification evidence. Structural JSON checks do not satisfy runtime gates. Track executed/pass/fail/not run/blocked separately. No stable release until all applicable gates pass.
